# 数据目录记录规则

## 农业权威报告

以后在本工作区查找或使用农业领域的权威报告时，将报告中的重要信息整理并保存到 `data` 目录，便于后续分析和核对。

- 每份报告单独记录，标题使用报告的正式名称。
- 记录发布机构、发布日期、原始链接或本地文件路径，以及检索日期。
- 摘录或概括与分析相关的重要事实、数据和结论；注明统计期间、单位、口径和关键假设。
- 标出预测与实际值、报告版本及后续修订，避免把不同版本混为一谈。
- 保留必要的不确定性和局限说明；只保存有用摘要与数据，不整篇复制受版权保护的报告。
- 如果已有同一报告的记录，优先更新原记录并注明版本/修订日期；必要时保留历史版本以供比较。
