# 中国国储棉政策时间线（2008–2022）数据说明

生成时间：2026-09-25。用途：棉花牛市复盘（对照 102 白糖牛市框架的"库存分层/政策瓶颈"章节）。

## 关键结论速览

1. **收储积累期（2011–2014）**：三年敞开收储累计约 **1,594 万吨**（313 + 651 + 630），耗资约 1,945 亿元（仅前两年）。中国期末库存从 2010/11 的 230.9 万吨膨胀到 2013/14 的约 1,247 万吨，其中国储约 1,100 万吨——**全球同期库存增量几乎全部进了中国国储**（库消比一度 140%，占全球期末库存 50%+）。这就是 WASDE 表观库销比 2013–2015 高达 90%+ 的政策成因，分析必须剔除。
2. **去库存期（2016–2018）**：连续三年抛储累计成交 **839 万吨**，均价 14,224 元/吨，占当年国内用量的 30–39%；2019 年起降至 100 万吨以下。2020 年国储剩余不足 200 万吨。
3. **对牛市的含义**：
   - 2016/17 牛市 = 去库存拐点驱动：表观库存仍在下降通道，但**可贸易库存**（剔除国储）从 2015/16 起已快速收紧——与 97 报告的可贸易库存框架一致。
   - 2021 年抛储（63+40+17.5 万吨）发生在牛市中，市场解读"利空出尽"后上涨——政策投放对牛市的压制力随国储枯竭而衰减，这是与白糖 ISO 禁令类比的关键差异点。

## 口径与冲突说明

- 2012/13 收储量：人民网 651 万吨、中新网/高勇 650 万吨、南华(Wind) 662 万吨、中国经济网 12/24 时点 489 万吨。CSV 取 651（终值多源中位）。
- 2011/12 收储：313 万吨为 9/8–3/31 竞价成交；另 2011 年 11 月起加收新疆棉约 100 万吨（南华"313+100"）。
- 2019 抛储：中棉行协 99.6 万吨 vs 南华 116 万吨（或含新疆棉定向）。
- 2015 抛储成交仅 6.34 万吨——低价差下流拍，去库存实际失败的标志性事件。
- 2008/09 收储 272 万吨细分口径待核实（150 万吨竞买 + 新疆棉等）。
- 2023 年后轮入轮出未收录（超出本轮牛市复盘所需窗口，可后续补充）。
